# Books to Scrape - Web Scraping Project

## Overview

This project is a web scraping application built with Python using Requests and BeautifulSoup.

The scraper collects book information from the Books to Scrape website and stores the extracted data into a CSV file.

Website:
https://books.toscrape.com/

---

## Features

- Scrapes all 50 pages
- Collects 1000 books
- Extracts:
  - Title
  - Price
  - Rating
  - Availability
  - Book Link
  - Category
  - Description
  - UPC
  - Product Type
  - Price (excluding tax)
  - Price (including tax)
  - Tax
  - Number of Reviews

- Saves data into CSV format

---

## Technologies Used

- Python
- Requests
- BeautifulSoup4
- CSV
- urllib.parse

---

## Output

The scraper generates:

books_data.csv

containing information for all 1000 books.
